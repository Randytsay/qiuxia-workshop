第五章

📊 Google 試算表設定

這是整個系統的「資料庫」。本教學的核心技巧是： 不需要任何 Google API 金鑰， 只需要把試算表「發布到網路」，就能直接讀取 CSV 資料！

核心原理：為什麼不用 API？

傳統方法（困難，不推薦）

1.前往 Google Cloud Console 建立專案
2.啟用 Google Sheets API
3.建立 OAuth 2.0 憑證
4.處理憑證下載與環境變數
5.處理權限與刷新權杖
6.寫程式呼叫 API、處理回應
❌ 困難點：需要設定、金鑰、憑證刷新token，對新手極不友善

我們的方法（簡單，強烈推薦）

1.在 Google Sheets 建立資料
2.點擊「檔案 → 發布到網路」
3.選擇「逗號分隔值（.csv）」格式
4.複製產生的 URL
5.在 JavaScript 用 fetch() 直接抓取
✅ 優點：零設定、零金鑰、立即可用，缺點是試算表必須設為「知道連結的人都能查看」
A

建立 Google 試算表

按照以下格式建立你的資料表。資料格式是成敗的關鍵。

1.

前往 Google Sheets 並建立新試算表

打開瀏覽器，進入：https://sheets.google.com

登入你的 Google 帳號，點擊「空白」建立一個新的試算表。

2.

命名工作表

點擊左上角的「未命名試算表」，改成有意義的名稱，例如：秋霞大C出席記錄。

3.

設計資料格式（最重要！）

在第一列（列 1）輸入欄位名稱（Header），從第二列（列 2）開始填入資料。 欄位名稱絕對不能有空格或特殊符號。

📋 格式一：秋霞大C 出席記錄表

時間戳記 日期 姓名 小C名稱 新朋友數
2026/01/01 10:00:002026/01/05王小明台北小C1
2026/01/01 10:02:002026/01/05陳大華新竹小C2
2026/01/01 10:05:002026/01/05林美麗台北小C0

📌 欄位說明： 時間戳記 = Google Form 自動填入（可省略）， 日期 = 格式為 YYYY/MM/DD， 新朋友數 = 數字（代表這位夥伴有幾位新朋友）

📋 格式二：工作坊參與記錄表

參與工作坊日期 工作坊類別 參與者姓名 所屬小C
2026/03/15經營工作坊王小明台北小C
2026/03/15經營工作坊陳大華新竹小C
2026/03/20AI工作坊林美麗台北小C

⚠️ 重要：欄位命名規則

  • • 絕對不能有空格： 用 小C名稱 而不是 小C 名稱
  • • 不要用特殊符號： 避免 @#$%^&* 等
  • • 建議用英文或中文： date 或 日期 都可以
  • • 第一列固定是 Header： 不要從第 0 列開始填資料
  • • 日期格式建議： YYYY/MM/DD（例如 2026/04/01），程式解析最穩定
  • • 數字不要加逗號： 存 1000 而不是 1,000

D

手動建構 CSV URL（推薦收藏）

除了「發布到網路」產生的連結，你也可以從網址列直接取得試算表 ID，手動組合 CSV URL。

1.

從網址列複製試算表 ID

打開試算表，網址列 URL 長這樣：

https://docs.google.com/spreadsheets/d/
1NvM2cZEeLWScclaoO6Lf0JpSNuaBhxms9P4UdZSPJSk
/edit#gid=0

中間那一大串英文數字就是試算表 ID（Spreadsheet ID）。

2.

手動組合 CSV 匯出 URL

把試算表 ID 填入這個格式：

https://docs.google.com/spreadsheets/d/
你的試算表ID
/export?format=csv

如果有多個工作表，可以加上 gid=工作表數字 指定要哪一張。

💡 什麼是 gid？
gid 是「工作表 ID」。打開試算表時，切換到不同工作表分頁（如「Sheet2」），網址列的 #gid=123456 就會改變。
如果只有一張工作表，gid 通常是 0。
組合 URL 時：https://docs.google.com/spreadsheets/d/[ID]/export?format=csv&gid=0

2 第二部分：CSV 解析函式（處理複雜格式） 

/* 解析一行 CSV，處理「引號包住的逗號」等複雜情況
   例如："王小明, 台北","新朋友, 1" 這種情況 */
function parseCSVLine(line) {
  const result = [];
  let current = '';
  let inQuotes = false;   // 是否在引號內

  for (let i = 0; i < line.length; i++) {
    const ch = line[i];

    if (ch === '"') {
      // 如果是引號，且前一個字也是引號（""），則是跳脫的引號
      if (inQuotes && line[i + 1] === '"') {
        current += '"'; i++;     // 加入一個引號字元
      } else {
        inQuotes = !inQuotes;       // 否則是引號的開始或結束
      }
    } else if (ch === ',' && !inQuotes) {
      // 如果是逗號且不在引號內，代表一個欄位結束
      result.push(current);
      current = '';
    } else {
      current += ch;                // 否則把字元加入當前列
    }
  }
  result.push(current);  // 最後一欄也要加入
  return result;
}

💡 為什麼要這麼複雜？
標準 CSV 規定：如果欄位內容包含逗號，要用雙引號包住。 例如 "王小明, 台北",1 代表第一欄是「王小明, 台北」（含逗號），第二欄是 1。 所以解析器必須知道「引號內的逗號不是分隔符」。

3 第三部分：抓取並解析 CSV 資料 

/* ── 快取機制 ─────────────────────────── */
let _cache = null;       // 快取的資料
let _cacheTs = 0;      // 快取的時間戳記

export function clearCache() {
  _cache = null;
  _cacheTs = 0;
}

/* getAllData() — 從 Google Sheets 抓取所有原始資料
   使用 fetch() API（非同步 HTTP 請求） */
export async function getAllData() {
  const now = Date.now();

  /* 如果快取存在且未過期，直接回傳快取（避免重複請求） */
  if (_cache && now - _cacheTs < AUTO_REFRESH_INTERVAL) {
    return _cache;
  }

  /* ── Step 1: fetch() 發送 HTTP 請求到 Google Sheets CSV URL ── */
  const res = await fetch(CSV_URL);

  /* 檢查 HTTP 狀態碼。如果不是 200~299，代表失敗 */
  if (!res.ok) {
    throw new Error(`CSV fetch failed: ${res.status}`);
  }

  /* ── Step 2: 將回應轉換成純文字（我們要的是 CSV 文字） ── */
  const text = await res.text();

  /* ── Step 3: 按換行符號分割，得到每一列資料 ── */
  const lines = text.trim().split('\n');

  /* ── Step 4: 解析每一列，跳過第一列（表頭） ── */
  const rows = lines.slice(1).map(line => {
    const cols = parseCSVLine(line);  // 解析一行 CSV
    return {
      timestamp:    cols[0] || '',     // 第 0 欄：時間戳記
      date:         normalizeDateStr(cols[1]) || '',  // 第 1 欄：日期
      name:         cols[2]?.trim() || '',          // 第 2 欄：姓名
      subgroup:     cols[3]?.trim() || '',          // 第 3 欄：小C名稱
      newFriends:  parseInt(cols[4]) || 0,          // 第 4 欄：新朋友數（轉數字）
    };
  });

  /* ── Step 5: 過濾掉日期或小C為空的列 ── */
  _cache = rows.filter(r => r.date && r.subgroup);
  _cacheTs = now;
  return _cache;
}

💡 完整流程圖：
fetch(CSV_URL) → HTTP 請求發出 → Google Sheets 回傳 CSV 文字 → res.text() 取文字 → split('\n') 切成列 → parseCSVLine() 每列切成欄 → .map() 組裝成物件陣列 → .filter() 過濾髒資料 → 乾淨的 JavaScript 物件陣列！

4 第四部分：依日期取得單日統計（fetchAnalytics） 

/* fetchAnalytics(date) — 根據日期，計算該日各小C的出席統計
   回傳格式：{ subGroupData, totalPartners, totalNewFriends, grandTotal } */
export async function fetchAnalytics(date) {
  const data = await getAllData();     // 先抓所有原始資料

  /* ── Step 1: 過濾出指定日期的所有記錄 ── */
  const filtered = data.filter(r => r.date === date);

  /* ── Step 2: 按小C分組統計 ── */
  const subgroupMap = {};          // { '台北小C': { name, partners, newFriends, attendees: [] } }
  let totalPartners = 0;
  let totalNewFriends = 0;

  for (const row of filtered) {
    /* 如果還沒有這個小C，先建立一筆 */
    if (!subgroupMap[row.subgroup]) {
      subgroupMap[row.subgroup] = {
        name: row.subgroup,
        partners: 0,
        newFriends: 0,
        total: 0,
        attendees: []
      };
    }
    const g = subgroupMap[row.subgroup];

    /* 1. 計入夥伴本人 */
    g.partners++;
    g.attendees.push({ name: row.name, type: 'partner' });

    /* 2. 展開新朋友（1位 → 直接叫"張大的新朋友"，
           2位以上 → "張大的新朋友-1", "張大的新朋友-2"） */
    for (let i = 1; i <= row.newFriends; i++) {
      g.newFriends++;
      g.attendees.push({
        name: row.newFriends === 1
          ? ${row.name}的新朋友
          : ${row.name}的新朋友-${i},
        type: 'friend'
      });
    }

    /* 更新小C總計 */
    g.total = g.partners + g.newFriends;
    totalPartners++;
    totalNewFriends += row.newFriends;
  }

  /* ── Step 3: 轉成陣列並計算總計 ── */
  const subGroupData = Object.values(subgroupMap);

  return {
    subGroupData,                   // 各小C的詳細資料（含人名列表）
    totalPartners,
    totalNewFriends,
    grandTotal: totalPartners + totalNewFriends
  };
}

🔧 進階技巧與疑難排解

一些常見問題的解決方案，以及讓你的專案更上一層樓的技巧。

🔴 錯誤：fetch() failed

常見原因：Google Sheets 未正確發布為 CSV 格式，或 CSV URL 無效。

確認「發布到網路」選擇的是「逗號分隔值（.csv）」
在瀏覽器新分頁直接打開 CSV URL，確認能看到純文字 CSV
確認分享權限設為「知道連結的任何人」
檢查 gid 是否正確（每個工作表有不同的 gid）

🟡 錯誤：Module not found

常見原因：忘記執行 npm install，或路徑拼錯。

確認在專案根目錄執行 npm install
檢查 import 路徑是否正確（大小寫有差別！）
刪除 node_modules 資料夾，重新執行 npm install

🟠 錯誤：CORS policy

常見原因：本地開發時瀏覽器阻擋跨網域請求。

Vite 開發伺服器已內建處理 CORS，不需要另外設定
Vercel 部署後仍有 CORS 問題，檢查 vercel.json 的 headers 設定
確認 CSV URL 是 Google Sheets 的 export 格式，不是分享連結格式

🟢 問題：圖表沒有顯示

圖表容器存在，但沒有內容。

確認圖表容器有設定寬度和高度（例如 style="width:100%;height:400px"）
Chart.js 需要容器有明確尺寸，flex/grid 父容器可能需要額外設定

在開始寫程式之前，我們需要準備好基礎設施。

  • 進入 Google Sheets
  • 確保能夠建立新的試算表

  • 選擇 Continue with GitHub（最推薦）
  • 點擊授權即可完成綁定
1

Google 試算表
詳細設定

這是你的「資料庫」。小白最常失敗的地方在於權限設定。請務必跟著以下步驟操作。

⚠️ 核心原理 ⚠️

我們不使用複雜的 Google API 授權，而是利用「公開發布」產生的 CSV URL。 這可以繞過繁瑣的登入流程，讓網頁直接讀取純文字數據。

A 建立正確的資料格式

試算表的第一列（Header）必須乾淨，不要有空格或特殊符號。

日期姓名區域出席狀態
2026/01/01張小明台北已簽到

B 發布至網路（關鍵步驟）

  1. Step 1. 點擊左上角 [檔案] → [共用] → [發布到網路]。
  2. Step 2. 在彈窗中，第一個下拉選單選擇「整份文件」或「特定工作表」。
  3. Step 3. 重要：第二個下拉選單務必選擇 「逗號分隔值 (.csv)」。
  4. Step 4. 點擊藍色的「發布」按鈕，並複製產生的連結（這就是你的 API URL）。
小提示

如果你更新了試算表的內容，通常需要等 1-5 分鐘，Google 才會同步更新 CSV 連結的內容。這不是你的程式壞掉囉！

開發邏輯與
原理解析

不需要安裝任何開發軟體，只要一個記事本或線上編輯器就能完成。我們將解釋每一行程式碼的意義。

A. 核心 HTML 結構

我們只需要三個部分：圖表容器、數據抓取腳本、圖表展示腳本。

<!DOCTYPE html>
<html>

    <!-- 這是一個空的畫布，圖表會畫在這裡 -->
    <div id="chart-main" style="width: 100%; height: 500px;"></div>

</html>

B. 資料解析 JS (小白必讀)

這段程式碼的功能是把「一長串文字」變成電腦看得懂的「一組組物件」。

async function fetchData() {
    // 1. 抓取剛剛複製的 CSV 連結
    const response = await fetch('你的_CSV_連結');
    const text = await response.text();

    // 2. 將每一列切割開來
    const rows = text.split('\n');
    
    // 3. 處理表頭 (第一列)
    const headers = rows[0].split(',');

    // 4. 組裝資料
    const cleanData = rows.slice(1).map(row => {
        const cols = row.split(',');
        return {
            date: cols[0], // 假設第一欄是日期
            value: Number(cols[1]) // 假設第二欄是數值
        };
    });
    
    renderChart(cleanData);
}

階段 3：GitHub 與 Vercel 部署

最後一里路：把檔案發布到網路上，全世界都能看到。

A

上傳程式碼至 GitHub

1

點擊 GitHub 頁面右上角 [+] → [New repository]。

2

Repository name 輸入 my-dashboard。設為 Public。

3

建立後，在頁面中央找到 "uploading an existing file" 並點擊。

4

將你的 index.html 拖進去，點擊 [Commit changes]。完成！

B

連結 Vercel 部署網址

1

在 Vercel 後台點擊 [Add New] → [Project]。

2

找到剛建立的 my-dashboard 儲存庫，點擊 [Import]。

3

直接點擊藍色的 [Deploy] 按鈕（無需更改任何設定）。

4

恭喜！ Vercel 會給你一個網址，例如 my-dashboard.vercel.app。
